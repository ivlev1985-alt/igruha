# 3.2. Главное меню — обновлённая спецификация

Меняю местами центр и правую колонку (теперь Кнопки в центре, Личные рекорды справа). В нижней панели оставляю только ежедневные награды — сразу 7 штук на неделю.

---

## 3.2.1. Общая концепция

Главное меню — **единый экран без прокрутки**:
- Заголовок игры.
- **Рейтинг игроков** (слева).
- **Кнопки управления** (по центру).
- **Личные рекорды** (справа).
- **Задача дня** (слева внизу) и **Достижения** (справа внизу).
- **Ежедневные награды на неделю** (нижняя панель).

Экраны «Задача дня» и «Достижения» — **части главного меню**, видны сразу.

Палитра: чёрный фон, белый текст, красный акцент.

## 3.2.3. Зона 1: Заголовок

**Расположение:** по центру горизонтали, верхние 15% экрана.

**Элементы:**

1. **Название игры:** «ТРИ ЦВЕТА, ТРИ СТОРОНЫ»
   - Крупный, жирный, белый, верхний регистр, по центру.

2. **Разделитель:** горизонтальная красная линия под названием.
   - Ширина — 60% ширины названия.
   - Пульсирует: прозрачность от 0,6 до 1,0 с периодом 2 секунды.

3. **Подзаголовок:** «Обратная сторона медали»
   - Мелкий, курсив, белый с прозрачностью 0,7.

**Фон:** чёрный.

**Анимация:** fade-in за 0,5 сек.

---

## 3.2.4. Зона 2: Рейтинг (слева)

**Расположение:** левая треть экрана, под заголовком.

**Заголовок:** «ТОП-10 ЗА РАУНД»
- Белый, мелкий, верхний регистр, по центру.

**Таблица (10 строк):**

| Место | Имя | Результат |
|---|---|---|
| 1 | Игрок123 | 100/100 |
| 2 | Мастер | 88/88 |
| 3 | Новичок | 71/71 |
| ... | ... | ... |

- Место — белое, мелкое.
- Имя — белое, среднее.
- Результат — белое, жирное.
- Первое место — красная обводка вокруг строки.

**Анимация:** при обновлении — новая строка **вспыхивает красным** и занимает своё место (сдвиг 0,3 сек).

**Источник данных:** локальный рейтинг + фиктивные имена для атмосферы. Синхронизация с облаком, если игрок авторизован.

---

## 3.2.5. Зона 3: Центр — Кнопки

**Расположение:** центральная треть экрана, под заголовком.

**Три кнопки, вертикально, по центру:**

1. **ИГРАТЬ**
   - Самая крупная (в 1,5 раза выше остальных).
   - Белый фон, чёрный текст.
   - При наведении — красная обводка.
   - При нажатии — уменьшение (0,95) и вспышка красным.

2. **КАК ИГРАТЬ**
   - Средняя.
   - Чёрный фон, белая обводка, белый текст.
   - При наведении — обводка красная.
   - Открывает экран «Как играть».

3. **НАСТРОЙКИ**
   - Средняя.
   - Чёрный фон, белая обводка, белый текст.
   - При наведении — обводка красная.
   - Открывает экран настроек.

**Расстояние между кнопками:** одинаковое.

**Анимация:** появление каскадом с задержкой 0,1 сек.

## 3.2.6. Зона 3: Правая колонка — Личные рекорды

**Расположение:** правая треть экрана, под заголовком.

**Заголовок блока:** «ЛИЧНЫЕ РЕКОРДЫ»
- Белый, мелкий, верхний регистр, по центру.

**Элементы (вертикальный список, по центру):**

1. **Лучший раунд**
   - Подпись: «Лучший раунд:».
   - Значение: «66/66».

2. **Лучший за всё время**
   - Подпись: «Лучший за всё время:».
   - Значение: «412/412».

3. **Всего партий**
   - Подпись: «Партий:».
   - Значение: «47».

4. **Всего побед**
   - Подпись: «Побед:».
   - Значение: «12».

**Разделители:** тонкие серые линии между пунктами.

**Анимация:** при обновлении рекорда — значение **мигает красным** 1 секунду.

## 3.2.7. Зона 4: Задача дня (слева) и Достижения (справа)

Нижняя часть экрана (до панели наград) делится **на две половины**.

### Левая половина: Задача дня

**Заголовок:** «ЗАДАЧА ДНЯ»
- Белый, мелкий, верхний регистр.

**Содержимое панели:**
- Фон: чёрный с белой обводкой (прозрачность 0,3).
- **Описание:** «Фиксированный сид. Одна попытка. У всех одинаково.»
- **Статус:**
  - Если не пройдена: «Не пройдена».
  - Если пройдена: «Пройдена: 66/66» (красным акцентом).
- **Кнопка «ПОПРОБОВАТЬ»:**
  - Белый фон, чёрный текст.
  - Если задача уже пройдена сегодня — кнопка **неактивна** (серая), текст «ПРОЙДЕНА».
  - Под кнопкой мелкий текст: «Следующая через 12:34:56» (таймер до полуночи).

**Анимация:** если задача не пройдена — кнопка **пульсирует белым**.

### Правая половина: Достижения

**Заголовок:** «ДОСТИЖЕНИЯ 12/30»
- Белый, мелкий, верхний регистр.

**Содержимое панели:**
- Фон: чёрный с белой обводкой (прозрачность 0,3).
- **Список последних 5 достижений:**
  - Пройденные: галочка ✓ (красная), название белым.
  - Непройденные: пустой кружок ○ (серый), название белым с прозрачностью 0,5.
- **Пример:**
  ```
  ✓ Первая победа
  ✓ 60/60
  ✓ 100 партий
  ○ 66/66
  ○ 10 побед подряд
  ```
- **Кнопка «ВСЕ ДОСТИЖЕНИЯ»** под списком:
  - Мелкая, белая обводка, белый текст.
  - Открывает отдельный экран достижений.

## 3.2.8. Зона 5: Ежедневные награды (нижняя панель)

**Расположение:** самый низ экрана, высота 15%.

**Заголовок:** «🔥 Серия: N дней»
- Красная иконка огня, белый текст.
- По центру над сеткой наград.

**Сетка наград на неделю (7 ячеек в ряд):**

```
┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐
│ ✓ │ │ ✓│ │🎁 │ │   │ │   │ │   │ │   │
│ 1 │ │ 2 │ │ 3 │ │ 4 │ │ 5 │ │ 6 │ │ 7 │
└───┘ └───┘ └───┘ └───┘ └───┘ └───┘ └───┘
```

- **Пройденные дни** — галочка ✓ (красная), номер белым, фон чёрный с белой обводкой.
- **Сегодняшний день** — пульсирует красным, иконка 🎁, номер белым.
- **Будущие дни** — серые, номер белым с прозрачностью 0,5.
- **7-й день** — особая рамка (красная, толстая), потому что награда уникальная.

**Под сеткой:**
- **Текст сегодняшней награды:** «Сегодня: +2 рекламных пропуска» — белый, средний, слева.
- **Кнопка «ЗАБРАТЬ»:** белый фон, чёрный текст, справа.
  - Если награда уже забрана — неактивна (серая), текст «ЗАБРАНА».
  - При нажатии — награда зачисляется, ячейка меняется на ✓, кнопка становится неактивной.

**Анимация:**
- При получении награды — ячейка **вспыхивает красным** и превращается в галочку.
- Если серия сброшена (пропущен день) — все ячейки **мигают серым** и сбрасываются на 1.

**Источник данных:** локально / облако. Дата последнего входа, номер дня серии.

## 3.2.11. Анимации при запуске меню

1. **0,0 сек** — чёрный экран.
2. **0,3 сек** — заголовок fade-in.
3. **0,6 сек** — красная линия пульсирует.
4. **0,9 сек** — Рейтинг fade-in.
5. **1,2 сек** — Кнопки появляются каскадом.
6. **1,5 сек** — Личные рекорды fade-in.
7. **1,8 сек** — Задача дня и Достижения fade-in.
8. **2,1 сек** — Ежедневные награды fade-in.
9. **2,4 сек** — меню готово.

**Звук:** мягкий щелчок при появлении каждой зоны.

## 3.2.13. Итог

Главное меню — **одноэкранное**:
- **Слева** — рейтинг игроков.
- **По центру** — кнопки управления.
- **Справа** — личные рекорды.
- **Внизу слева** — задача дня.
- **Внизу справа** — достижения.
- **Самый низ** — ежедневные награды на неделю (7 ячеек).

Игрок заходит — и сразу видит всё: прогресс, рейтинг, что можно сделать сегодня, и забирает награду без лишних кликов.
